KOGEI / PLAY — 3D試作版

1. index.html, styles.css, app.js, three-preview.js をリポジトリ直下に配置してください。
2. 既存の assets/materials/ 内の画像はそのまま残してください。
3. 素材画像名は white.jpg, red.jpg, celadon.jpg, iron.jpg, beech.jpg, cedar.jpg, black-lacquer.jpg, vermilion-lacquer.jpg, wipe-lacquer.jpg, bamboo.jpg, glass.jpg など、素材IDと同名にしてください。jpg/jpeg/png/webpを順に探します。
4. Three.jsをCDNから読み込むため、初回表示にはインターネット接続が必要です。CDNやWebGLが使えない環境では既存の2D SVGにフォールバックします。
5. 3D形状は軽量な回転体モデルです。立方体・片口・籠などの固有形状は今後の造形改良が必要です。保存はJPEGサムネイル（3D描画結果）です。
6. GitHub Pages反映後に Ctrl+Shift+R で再読み込みしてください。
